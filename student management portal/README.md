# Responsive Student Management Portal

## Project Overview

The Student Management Portal is a responsive web application developed using HTML5, CSS3, Bootstrap 5, and JavaScript.

The portal helps manage:

- Student Registration
- Student Profiles
- Attendance Management
- Results Management
- Dashboard Statistics
- Contact Information
